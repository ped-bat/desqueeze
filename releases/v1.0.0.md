# Version 1.0.0 (15 Oct 2026)

The first full release: a rebuilt interface, DNGs whose previews and
colours finally match the promise, and a trimmed platform list.

## Interface

- **A new working surface.** The ceremony screen is gone: files land in a
  list with per-row status and remove, actions live in a footer bar, and
  settings open in a popover instead of a separate screen. Screens
  crossfade; the dot grid, bars and type were tuned throughout.
- **New app icon.** The Desqueeze mark is now just the two bars — the
  arrows in the middle are gone.

## DNG output

- **Desqueezed previews.** Converted DNGs embed a preview rendered at the
  corrected proportions, so Finder, Explorer and culling tools show the
  desqueezed shape instead of the squeezed frame. (Viewers that decode the
  raw data but ignore `DefaultScale` — Apple's Preview and Photos — still
  show squeezed pixels; export a JPEG or TIFF for those.)
- **Correct colours for Sony lossless M/S raws.** These files are stored
  already white-balanced, which the DNG now declares the way Adobe DNG
  Converter does — including the camera's unapplied balance from Sony's
  maker notes. Converted files now open in Lightroom with the same
  temperature, tint and colour as the original ARW; previously they could
  land far off (strong red/blue casts) even at matching slider values.
- `DefaultScale` is pinned to the IFD that actually holds the raw image,
  wherever DNGLab put it.

## Platforms

- Desqueeze now ships for **macOS (Apple Silicon)** and **Windows x64**.
  The Linux AppImage is discontinued.
- Dependency updates across the board (Electron 44 line, sharp, undici
  and friends).
