# Version 0.1.1 (2 Sep 2026)

## Bugs fixed

- **Windows: "conversion failed" on a clean install.** The bundled
  `dnglab.exe` and `dcraw_emu.exe` import the Visual C++ runtime, which is
  not part of Windows. On a machine without the redistributable installed
  they died at process start (exit code `0xC0000135`) with no error output
  at all, so the app could only report a generic failure. The runtime DLLs
  are now bundled alongside the binaries.
- **Clearer conversion errors.** When a bundled tool fails, the app now
  shows the tool's own message (e.g. `dnglab: Error: Not found: …`) instead
  of echoing the command line back at you.

## Maintenance

- Updated Electron (39.8.10), sharp (0.35.4) and vitest (4.1.11) to pick up
  upstream security fixes.
- The release workflow no longer breaks when macOS signing secrets are
  absent — it produces an unsigned build and warns, instead of failing.
