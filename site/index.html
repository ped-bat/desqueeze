Built for anamorphic photography

  • Lossless by default

    In DNG mode the squeeze factor is written as metadata, the DefaultScale tag, and every pixel stays where the sensor put it. Lightroom, Camera Raw and any other DNG-aware app read the tag and show the image at its true proportions. Nothing is resampled, so nothing is lost, and it can be undone.

  • Offline and private

    Everything runs on your machine. No account, no uploads, no telemetry. The converters it relies on, DNGLab, dcraw_emu and ExifTool, ship inside the app, so there is nothing else to install.

  • RAW in, DNG out

    Reads 25 RAW formats from 825 cameras across 32 manufacturers, plus JPEG, PNG, TIFF and WebP. Bitmaps get a proper colour profile on the way to DNG, and you can export a flat JPEG, PNG, TIFF or WebP instead when that is what you need.

  • Free and open source

    MIT licensed, with every line on GitHub. It was built for one anamorphic lens and one Lightroom catalogue; it may be useful for yours too.

Drop, set, done

  1. Drop files

    Drag photos or whole folders anywhere onto the window, or choose them from a dialog.

  2. Set the factor

    Pick your lens's squeeze: 1.33x, 1.5x, 2x or a custom value. Keep DNG for a lossless result, or choose JPEG, PNG, TIFF or WebP for a flat file.

  3. Desqueeze

    Files are processed in parallel and land in a desqueezed folder next to the originals, which are never touched.

Common questions

What does lossless mean here?

In DNG mode nothing is resampled. Desqueeze writes the squeeze factor into the file's DefaultScale tag and leaves the pixel data untouched. Lightroom, Camera Raw and other DNG-aware apps apply the scale when they open the file, and the tag can be changed or removed later. The other output formats bake the stretch into the pixels, which is a real resample, so choose DNG when quality matters.

Which files does Desqueeze accept?

RAW: 3fr ari arw cr2 cr3 crw dcr dcs dng erf iiq kdc mef mos mrw nef nrw orf pef raf raw rw2 sr2 srf srw. Bitmaps: jpg jpeg png tif tiff webp. Output is DNG, JPEG, PNG, TIFF or WebP.

Is my camera supported?

RAW decoding comes from DNGLab, which covers 825 cameras from 32 manufacturers. The full list is published in the repository. Bitmap files work regardless of camera.

Does it work offline?

Yes. Everything runs locally. DNGLab, dcraw_emu and ExifTool ship inside the app, so there is nothing else to install and no network access while processing.

Where do the files go?

Into a desqueezed folder next to the originals, which are never modified. Files that already carry a desqueeze are skipped rather than stretched twice.

Are Intel Macs supported?

Not yet. The macOS build is for Apple Silicon. Windows (x64) and Linux (x86_64) builds are available.
